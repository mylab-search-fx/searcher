## Что оставить

Индекс как граница сущности. Именованные фильтры и сортировки. Обязательные ограничения, которые клиентский запрос не снимает. Свободный текст отдельно от точных условий. Стратегия should или must как настройка индекса.

## Чем заменить части

Заменять стоит механизм, а не весь поиск. Движок менять имеет смысл только если продукт — это подсказки по префиксу, а не выборка с фильтрами.

| Замена                                     | Закрывает                                     | Брать, когда                                                 |
| :----------------------------------------- | :-------------------------------------------- | :----------------------------------------------------------- |
| Приватный вызов из своего API              | Токен, публичный канал, SignKey на краю       | Браузер и так ходит в бэкенд, который знает пользователя     |
| Search template Elasticsearch              | Файлы JSON и текстовую подстановку аргументов | Готовы остаться на Query DSL и хотите меньше своего компилятора |
| Типизированный предикат                    | Сырой DSL в каталоге фильтров                 | Нужен свой стабильный язык и возможность сменить движок      |
| multi_match и search_as_you_type           | Regexp по text-полям и вес по номеру слова    | Нужны слово, фраза и префикс, а даты и числа приходят отдельными полями |
| Filtered alias или document-level security | Обязательный фильтр внутри JWT                | Ограничение — свойство документа: владелец, регион, организация |
| Непрозрачный токен в хранилище             | Неотзываемый JWT и вечный доступ без exp      | Публичная точка остаётся и права надо гасить до истечения срока |

## Целевая форма

Компилятор

Принимает текст, список id фильтров с типизированными аргументами, id сортировки и курсор. Собирает запрос в Elasticsearch из проверенного каталога.

Политика снаружи

Бэкенд решает, какие индексы, обязательные предикаты и разрешённые фильтры доступны. Searcher проверяет подпись или принимает вызов только из приватной сети.

Предикаты

Фильтр описывает поле, оператор и тип параметра. Query DSL появляется на выходе компилятора. На старте каталог сверяется с мэппингом индекса.

## Порядок изменений

### Сначала граница доверия

Выпуск токена уезжает к владельцу политики. На публичном Searcher остаётся проверка. Срок жизни обязателен. В токене есть jti. Клиентский фильтр обязан входить в allowlist, обязательные фильтры клиент не выбирает.

### Затем язык запроса

Свободная строка ищет только по текстовым полям, заданным для индекса. Число, дата и диапазон приходят отдельными аргументами именованного фильтра. Совпадение всей фразы сохраняет повышенный вес. Вес «чем левее слово, тем важнее» уходит из ядра ранжирования.

### Потом выдача и контракт

Курсор вместо глубокого offset. Потолок limit. Отладочный запрос Elasticsearch только во внутреннем ответе. README и OpenAPI описывают одну и ту же форму: entities, total, индекс в пути indexes.
